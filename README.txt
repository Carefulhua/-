# 发票PDF批量重命名工具

## 功能说明
自动读取发票PDF文件内的信息，提取：
- 发票号码
- 项目名称
- 价税合计金额

并自动将文件名改为：`[发票号码]_[项目名称]_[价税合计].pdf`

## 发票目录要求
1. 把所有要处理的发票PDF文件放在**同一个文件夹**内
2. 程序会自动识别该文件夹下的所有PDF文件
3. **建议**：把发票PDF单独放一个文件夹，避免误处理其他文件

## 使用步骤

### 步骤1: 准备发票文件夹
把发票PDF文件放在一个文件夹里，例如：
- `D:\发票` 
- `D:\我的发票`
- 桌面上的一个文件夹

### 步骤2: 运行程序
**方法A（推荐）**：双击 `run-exe.bat`

**方法B**：在命令行运行
```
invoice-renamer.exe D:\发票
```

### 步骤3: 查看结果
程序运行后会显示每个发票的处理结果，重命名后的文件名格式：
```
26317000000318446404_运输服务_客运服务费_25.97.pdf
26319132270000061764_G1633次_86.00.pdf
26312000000121260826_餐饮服务_【暖手茶】白_98.08.pdf
```

## 支持的发票类型
- ✅ 增值税普通发票
- ✅ 火车票
- ✅ 打车发票（高德打车等）

## 文件说明
| 文件 | 作用 |
| --- | --- |
| `run-exe.bat` | 一键运行：先改名，再生成 Excel 汇总 |
| `invoice-renamer.exe` | 改名程序（由 `invoice-renamer.py` 打包） |
| `invoice-renamer.py` | 改名程序源码 |
| `invoice-to-excel.py` | 汇总 Excel 程序 |
| `invoice_parser.py` | 发票文本解析（改名和汇总共用，改识别规则只改这里） |
| `test_invoice_parser.py` | 回归测试：`python test_invoice_parser.py` |

## 识别规则
- 价税合计优先按"价税合计（大写）"的中文大写金额解析，例如 `贰佰肆拾叁圆壹角整` → `243.10`。
  这样不受 PDF 文字流顺序影响（部分发票"（小写）"后面紧跟的是"合计金额"，直接取小写数字会取错）。
- 项目名称取 `*类别*品名`，跨行断开的中文会自动拼接（如 `usb风` + `扇` → `usb风扇`），
  并按词边界截断，不会出现 `双频Wi-` 这种截一半的情况。

## 重新打包
如果需要重新打包成EXE，运行：
```
build-python.bat
```
注意：改完 `invoice_parser.py` 后必须重新打包，EXE 里是打包时的代码。

## 注意事项
- 程序会在当前目录创建/修改PDF文件名
- 如果目标文件名已存在，会自动加上数字后缀
- 如果无法识别发票信息，该文件不会被重命名
